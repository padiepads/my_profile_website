# Jerald J. Padellon | Portfolio

Sections: Home, About, Projects & Certificates, Contact.
Stack: HTML, CSS, JavaScript, plus `app.py` (Python) for the optional live API demo.

## Run locally
- Open the folder in VS Code and use Live Server on `index.html`.
- Optional: run `python app.py` to make the "Try the Python backend" demo answer live from http://localhost:8000.

## Deploy (free, no GitHub account needed)
**Netlify Drop (easiest):** go to https://app.netlify.com/drop and drag the whole portfolio folder in. You get a public link right away. You can rename it under Site settings, then Change site name.
**Alternatives:** Cloudflare Pages (direct upload) or GitHub Pages.

After you get your URL, replace `https://YOUR-SITE-URL/` in `index.html` (canonical, og:url, og:image), `robots.txt`, and `sitemap.xml`, then redeploy.

## Update plan
- New project: copy the Barangay CINCO card in `index.html` (Projects section) and edit it.
- New certificate: replace the "No certificates yet" box with a `.timeline` item.
- New skill: copy a `.skill-card` in the About section.
- Redeploy by dragging the folder to Netlify again.
- If employed or given an industry project: review and update the site regularly.
